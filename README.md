# actgenerator — генератор актов КСБ-СОФТ

Небольшая программа для Windows: вы заполняете одну форму, а она сама собирает из Word-шаблонов готовый комплект документов:

- **Акт установки и готовности к вводу в эксплуатацию СЗИ** (по договору или по контракту);
- **Сертификат технической поддержки**;
- **Акт испытаний**.

Ничего устанавливать не нужно: только **Windows, Microsoft Word и PowerShell** (встроен в Windows).

---

## Быстрый старт

1. Скачайте репозиторий (**Code, затем Download ZIP**) и распакуйте в любую папку, например `C:\actgenerator`.
2. Откройте папку `generator` и дважды щёлкните **`Сформировать.bat`**.
3. При первом запуске откроется окно «Настройки». Нажмите **«Найти автоматически»**. Программа найдёт папки `Шаблоны` и `Готовые`, которые лежат рядом с `generator`. Нажмите «ОК».
4. Заполните форму и нажмите **«Сформировать»**. Готовые файлы появятся в `Готовые\<номер> <заказчик>`.

Структура папок:

```
actgenerator/
  generator/   скрипты (Form.ps1, Generate.ps1, Common.ps1) и Сформировать.bat
  Шаблоны/     4 шаблона .docx (в них лежит весь текст актов)
  Готовые/     сюда сохраняются готовые акты
```

Инструкция со скриншотами формы и примерами готовых актов отправляется отдельно (PDF).

## Пример: Secret Net Studio + ViPNet для ООО «Ромашка»

Данные в примере вымышленные.

1. **Что оформляем.** Тип акта — «По договору». Укажите дату акта и дату установки. При желании отметьте «Сертификат ТП» и «Акт испытаний». У каждого документа своя дата: пока вы не меняли её вручную, она берётся из даты акта.
2. **Заказчик и договор.** Выберите или впишите заказчика, номер договора и дату. В поле номера вводите только цифры, префикс `СТКБ-` уже стоит. Заказчик запоминается, в следующий раз его можно выбрать из списка. Падеж для сертификата ТП подставляется автоматически.
3. **Что установлено.** Отметьте продукты. Вводите только последние цифры, остальное программа достроит сама:

   | Вы вводите            | В акте                                   |
   |-----------------------|------------------------------------------|
   | `177425` (Secret Net) | `РОСС RU.01.03745.177425`                |
   | `416554` (ViPNet)     | серийный № `КлКС2-4-416554`              |
   | рег. № ViPNet         | считается сам: `782-` + серийный № + 971 |

   Модули Secret Net Studio отмечаются галочками. Если снять галочку, пункт исчезнет из акта, а нумерация и знаки препинания поправятся сами.
4. **Рабочие места.** Одна строка в таблице — обычные пункты 6.3–6.5. Несколько строк — таблица рабочих мест.
5. **Исполнитель, сертификат, комиссии.** Выберите сотрудника из списка (кнопка «Сотрудники…» добавляет новых и правит данные), укажите продукты для сертификата ТП и состав комиссий для акта испытаний.
6. Нажмите **«Сформировать»** (или **Ctrl+Enter**). В папке `Готовые\СТКБ-873 ООО «Ромашка»` появятся три файла `.docx`.

## Удобства в форме

- **Ctrl+Enter** — «Сформировать».
- Если поле не заполнено, после сообщения курсор сам встаёт в это поле.
- Текст чистится сам: двойные пробелы, `г.Москва` становится `г. Москва`, пробелы у запятых.
- Перед созданием форма предупредит о странных датах: договор позже акта, договор в тот же день, что акт, испытания раньше установки.
- Галочка «Очищать форму после создания» удобна, когда акты идут подряд.

## Шаблоны

| Файл                           | Для чего                                                                    |
|--------------------------------|-----------------------------------------------------------------------------|
| `Акт_установки_Договор.docx`   | Secret Net / Dallas Lock / Континент TLS Клиент / ViPNet Client / КриптоПро |
| `Акт_установки_Составной.docx` | контракт: Prime / Coordinator / Континент / TLS-сервер                      |
| `Сертификат_ТП.docx`           | срок ТП правится прямо в этом файле                                         |
| `Акт_испытаний.docx`           | текст по Калужской области                                                  |

Шаблоны — обычные документы Word. Места, которые подставляет программа, записаны как `{{ИМЯ}}`, например `{{NOMER}}`. Блоки, которые включаются и выключаются (продукты, модули), помечены закладками Word (`blk_*`, `mod_*`, `loc_*`). Закладки и `{{...}}` при правке шаблонов нужно сохранять.

## Настройки

Папки шаблонов и готовых актов запоминаются в `generator\settings.json`. Файл создаётся при первом запуске, в репозитории его нет. Изменить пути можно кнопкой «Настройки (папки)» внизу формы. Если Word не открывает файл, сократите путь к папке `Готовые`: у Word лимит около 255 символов на путь.

## Перенос на другой компьютер

Скопируйте папки `generator`, `Шаблоны` и `Готовые`. `settings.json` копировать не нужно, на новом ПК он создастся сам.

## Чего в репозитории нет

Реальных данных заказчиков, договоров и готовых актов здесь нет.
